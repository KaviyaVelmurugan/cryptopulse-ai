# Changelog

All notable changes to CryptoPulse AI are documented here.

## [1.0.0] - 2026-09-01

### Added

- Versioned news, market, annotation, prediction, event and aggregate contracts
- Permitted NewsAPI and public Coinbase connector foundations
- Cleaning, quality flags and duplicate grouping
- Target-specific Bitcoin and Ethereum evidence extraction
- VADER evaluation and revision-pinned optional FinBERT comparison
- Explainable multi-label event classification with abstention
- Hourly and daily sentiment index with separate evidence coverage
- Chronological market-impact research with insufficient-sample safeguards
- SQLite operations, scheduling, health, readiness and read-only FastAPI endpoints
- Responsive Next.js dashboard, CSV/PDF workflow and local informational alerts
- MLOps monitoring, model registry, Docker, CI, dependency auditing and security policy
- Architecture, model card, data sheet, API reference and release documentation

### Responsible boundaries

- Synthetic sample outputs are not model-performance or investment claims
- Association is not causation
- No personalised advice, exchange credentials or trade execution
